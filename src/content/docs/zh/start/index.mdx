跟着这篇，你会在 Mac 上装好 OpenMausBot，和 Bot 说上第一句话，再交给它一件实际要做的事：**明天早上 9 点，把 Hacker News 上最热的 5 条新闻用中文总结后发给你。**

你需要：一台 Mac，以及 Claude（Pro 或 Max）或 ChatGPT 订阅。如果这台 Mac 上已经登录了 Claude Code 或 Codex，最省事。

<Steps>

1. **安装 App**

   从 [GitHub Releases](https://github.com/milind-soni/OpenMausBot/releases/latest) 下载对应芯片的 `.dmg`，拖进「应用程序」。也可以让你的 AI Agent 来做：

   ```text title="提示词"
   从 milind-soni/OpenMausBot 的最新 GitHub Release 下载适合这台 Mac 芯片的 .dmg，
   用 spctl --assess 确认已签名并公证，装到 /Applications 并打开。
   ```

   打开后你会看到一个类似聊天软件的界面，左边有一个叫 **MausBot** 的联系人。

2. **连接你的 AI**

   首次启动时，它会请你 **连接一个 AI**（本站称为「引擎」）。选你已经在用的 Claude 或 Codex：本机已经登录的话直接沿用。没登录的话，会让你在它们自己的网站上登录。不需要注册新账号。

3. **说第一句话**

   点左边的 **MausBot**，发送：

   ```text
   用一句话介绍你自己：你用的是哪个模型，能帮我做什么？
   ```

   它回复了，整个流程就通了：App → 你本机的 `claude` / `codex` 命令行 → 模型 → 返回。OpenMausBot 用的就是你本机已经登录的命令行，中间不经过别的服务。

4. **交给它一件实际的活**

   接着发送：

   ```text
   每天早上 9 点（按我的时区），打开 news.ycombinator.com，把最热的 5 条用中文各总结一句，
   附上原文链接发给我。先现在跑一次给我看。
   ```

   它通常会先现场跑一次，把 5 条总结发给你，再给自己建一个每天 9:00 的定时任务。建好后，对话里会出现一张卡片，写着任务的时间规则和接下来几次的运行时间。

5. **确认定时任务建好了**

   - **简洁模式**（新装 App 的默认界面）：点对话顶部的 **MausBot**，右边资料里的 **例行任务** 下能看到这条任务和下次运行时间。
   - **高级模式**：点左侧栏 **工具** 下的 **自动化**，点开这条任务能看到下次运行时间，也可以点 **立即运行** 手动跑一次。

</Steps>

这样就搞定了。现在你有一个**每天自动干活**的 Bot。明天早上 9 点，你会在 MausBot 的对话里收到第一份简报。

:::caution[在 Mac 上，Bot 拥有和你一样的权限]
新建的 Bot 默认是 **直接执行**：执行命令不会先问你，而且以你本人的 macOS 账号运行，能读到你的个人文件。想让它动手前先问你，点对话顶部的 Bot 名字，再点右上角的齿轮进入 **机器人设置**，在 **「Bot 名」行动之前** 里选 **先问我**，各档的区别见[审批级别](/zh/concepts/approval-levels/)。打算长期用的话，建议把 Bot 搬到[一台单独的服务器](/zh/guides/home-server/)上。
:::

:::note[Mac 合上盖子或睡眠时，定时任务不会跑]
定时任务由你电脑上的 App 来调度，电脑睡着或 App 退出时什么都不会跑，App 也没法唤醒睡着的 Mac。插着电时，它会在任务到点前一小时内防止电脑闲置睡眠，但合上盖子照样会睡。想 24 小时稳定运行，请参阅[Bot 应该跑在哪里](/zh/concepts/where-to-run/)。
:::
