OpenMausBot 的界面语言默认跟随系统，也可以在 **设置 → 通用** 里改。界面还分简洁模式（新装的默认）和高级模式（**设置 → 通用 → 高级模式**），两边有些叫法不同。下表列出本站用语和界面、命令行、团队文件里的叫法。

## 基本概念

| 本站用语 | 中文界面 | 英文界面 / CLI | 是什么 |
|---|---|---|---|
| Bot | 机器人 | bot | 聊天列表里的一个联系人，背后是一个 AI Agent，有自己的模型、记忆、工作目录和权限 |
| MausBot | 总协调机器人（高级模式「权限」里叫「幕僚长」） | Chief of Staff | 新装好后的第一个 Bot，可以给其他 Bot 派活，它对话的审批级别可能会带给它派出去的工作（有例外，见审批级别页） |
| 服务端 / 服务器 | 服务器；「把 X 设为我常用的」就是把 X 设为主服务器 | home、server | 运行 OpenMausBot 的那台机器。所有 Bot、登录和记忆都在这台机器上 |
| 引擎 | 简洁模式在 **设置 → AI** 里；高级模式叫「模型提供方」 | engine、provider | Bot 背后实际干活的 Agent CLI 或接口：Claude Code、Codex、OpenCode、Antigravity、OpenAI 兼容接口等 |
| 会话 | 对话；「新建对话」 | thread、`--task new` | 和某个 Bot 的一段对话。一件事开一个会话，上下文不会越积越大 |
| 常驻指令 | 简洁模式叫「指示」，高级模式叫「SOUL」 | Instructions / Soul、`SOUL.md` | 每一轮都会带上的指令，写这个 Bot 负责什么、遇到什么情况交给谁 |
| 技能 | 技能 | skill | Bot 存下来的做事方法，下次遇到同类任务直接照做 |
| 定时任务 | 例行任务；简洁模式在 Bot 资料里，高级模式在「工具 → 自动化」 | routine、Automations | 按时间表自动唤醒 Bot 干活，比如每天 9:00 |
| 团队文件 | —（命令行用 `team export` / `team apply`） | team file、`team.yaml` | 用一个 YAML 文件描述所有 Bot、房间、模型和权限，可以导出、修改、再应用 |
| 电脑 | 机器人的电脑（高级模式设置里叫「机器人桌面」） | computer：`vm`、`local`、`cloud`… | 给 Bot 用的桌面环境，它能在里面截图、点鼠标、打字 |
| 配对 | 配对 | pair | 让新设备（浏览器、桌面 App、手机）获得访问服务器的权限。自托管服务器的配对码默认 10 分钟内有效，只能用一次 |

## 审批级别

审批级别决定 Bot 做哪些事之前要先问你；完整说明见[审批级别](/zh/concepts/approval-levels/)。简洁模式在 **机器人设置** 的 **「Bot 名」行动之前** 里改（只有先问我和直接执行两档），也可以给当前对话单独选一档（能选哪几档看引擎）；高级模式在 **权限 → 批准层级** 里改。

| 简洁模式 | 高级模式 | 英文界面（简洁 / 高级） | 团队文件 / CLI | 行为 |
|---|---|---|---|---|
| 先问我 | 请求批准 | Ask me first / Ask for approval | `ask` | 通常在执行命令和改文件之前问你；Codex 和几类豁免例外 |
| 自动接受编辑 | 自动接受编辑 | Auto-accept edits | `edits` | 改文件不问，其他操作仍可能要问。只有 Claude、Grok、Antigravity、Qwen、Gemini 提供，OpenCode 和 Codex 没有 |
| 替我决定 | 代我批准 | Decide for me / Approve for me | `auto` | 引擎自带的自动审核放行常规操作，其余的问你；联网搜索不问。自动审核用不了时，其他审批请求通常退回询问；Antigravity 的「自动」等于完全访问 |
| 直接执行 | 完全访问 | Just do it / Full access | `full` | 不再弹出常规审批卡片（通过已连接的应用发送另有设置）。**新建的 Bot 默认是这一档**（公司托管的共享工作区默认先问我） |

几点说明：

- 无人值守的 Bot（跑定时任务、由 webhook 触发）如果是「先问我」，遇到要审批的操作就会停下来等没人批的卡片，等超时还会停止。碰不到敏感东西的无人值守 Bot，用「直接执行」更省心。
- 「直接执行」不会替你登录，也不会绕过验证码、多重验证和系统隐私权限。
- 审批卡片上有 **允许一次** 和 **拒绝**，按请求类型可能再多一个 **始终允许**。它管多大范围（这个工具、这条命令或这次会话）写在鼠标悬停的提示里。

## 教程里的写法约定

- **`<…>` 是占位符**，要换成你自己的值，比如 `<服务器IP>`、`<Bot 名>`。
- **`myserver`** 是示例服务器的 SSH 别名。换成你在 `~/.ssh/config` 里给自己服务器起的名字。
- **「交给 AI Agent」的提示词** 是写给 Claude Code、Codex、OpenCode 这类本机 Agent 的，整段复制给它即可。
- **「发给 Bot 的需求」** 是在 OpenMausBot 里直接发给某个 Bot 的消息。
- 界面路径写成 **设置 → AI** 的形式，使用简体中文界面的叫法；简洁模式和高级模式不同时会分别写。桌面 App 的系统菜单（如 **Server → Add Server from Copied Pairing Link…**）目前只有英文。
