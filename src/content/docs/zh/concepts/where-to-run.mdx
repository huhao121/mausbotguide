OpenMausBot 的所有 Bot 都**住在同一台机器上**：运行服务端的那台机器，同时运行所有 Agent 进程、保存所有登录。每台服务器都是一套独立的工作区。所以先选好这台主机，后面的事都跟着它定。

## 可选方案

| | 你的 Mac | 家里的小主机（Linux） | MausBot Cloud | VPS |
|---|---|---|---|---|
| 能直接用你已登录的订阅 | **能，开箱即用** | 要在服务器上再登录一次 | 要登录 | 要登录 |
| 笔记本合上后还能跑 | 不能：合上盖子 Mac 会睡，定时任务不跑 | **能** | **能** | **能** |
| 和你的个人文件隔离 | **不隔离**：Bot 以你本人的身份运行 | 隔离：单独的用户、单独的机器 | 隔离 | 隔离 |
| 桌面 App 专属能力（听写、操控本机桌面） | 有 | 没有（无界面的服务器） | 没有 | 没有 |
| 成本 | 免费 | 一次性买硬件（低功耗小主机就够） | Starter 每月 $15 起，可能另加税；不含 AI 用量（Pro、Max 每月含一些 Claude 额度） | 每月几美元起 |
| 配置难度 | 最低 | 一次性配置，可交给 Agent | 最低 | 中等 |

## 两边都跑过之后

我们在一台 Mac 和一台低功耗 Linux 小主机上都跑着 OpenMausBot。

- 小主机性能完全够用。模型跑在云端，服务端主要是启动 CLI 进程、等待结果。我们这台上同时跑着很多 Bot，按上下文大小分组，单次模型调用的中位数在 5 到 17 秒之间。觉得任务慢的时候，先看是不是[步骤太多](/zh/concepts/long-tasks/)。
- 不需要买大内存的本地 AI 盒子。除非你想在本地跑开源模型，否则服务端只是启动 CLI 进程和一个浏览器。我们这台是 4 核、16 GB 内存，跑着几十个 Bot，内存只用了 3 GB 左右，4 核、8–16 GB 绰绰有余。如果 Bot 要用本地虚拟桌面，每个运行中的桌面最多占 4 GB 内存和 2 个 CPU，同时开几个就按这个算。
- Mac 最大的好处是登录省事。Claude 和 Codex 本来就登好了，第一条消息就能用。在服务器上，有些引擎要多折腾几步（见[在服务器上登录引擎](/zh/guides/sign-in-engines/)）。
- Mac 最大的问题是隔离不够。Bot 执行的命令以你的 macOS 用户身份运行，能读到 `~/.ssh`、浏览器配置、整个 home 目录。在小主机上，它们以专用用户的身份运行在另一台机器上。

## 我们的建议

- **先试用：** 在你正在用的电脑上装桌面 App，跟 Bot 聊几句，看看合不合适。
- **决定长期用：** 把服务端搬到一台专用、常开的 Linux 机器（小主机或 VPS），Mac 和手机只当遥控器。这样 Bot 碰不到你个人电脑上的文件，还能 24 小时跑定时任务。它用你给的凭据连到的外部服务，仍然要靠审批级别和权限来管。
- **不想买硬件、不想运维：** 用 MausBot Cloud。最便宜的 Starter 不含 AI 用量，你仍然要接入自己的订阅；Pro 和 Max 每月含一些 Claude 额度，用完也要接自己的。
